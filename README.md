# Personal Website - CS Major with Art Minor

A beautiful, modern personal website designed specifically for a Computer Science major with an Art minor. This website showcases the perfect blend of technical skills and creative vision.

## Features

✨ **Modern Design**: Clean, elegant layout with beautiful gradients and animations
🎨 **Art-Inspired**: Creative elements that reflect your artistic background
📱 **Responsive**: Works perfectly on desktop, tablet, and mobile devices
⚡ **Interactive**: Smooth animations, hover effects, and engaging interactions
🎯 **Professional**: Perfect for showcasing your skills and projects

## Sections

- **Hero**: Eye-catching introduction with animated floating elements
- **About**: Personal story highlighting your CS and Art background
- **Skills**: Technical and creative skills organized by category
- **Projects**: Portfolio section (ready for your future projects!)
- **Contact**: Multiple ways for people to reach you

## Customization Guide

### 1. Personal Information
Edit the following in `index.html`:

- **Name**: Replace "Your Name" throughout the file
- **Email**: Update `your.email@example.com` in the contact section
- **Social Links**: Update LinkedIn, GitHub, and Instagram links
- **About Text**: Customize the about section with your own story

### 2. Skills
In the Skills section, you can:
- Add or remove programming languages
- Update art and design skills
- Modify the learning/soft skills section

### 3. Projects
The projects section currently shows placeholder cards. When you have projects:
- Replace the placeholder content with your actual projects
- Add real project images
- Include links to live demos or GitHub repos

### 4. Colors and Styling
The website uses CSS custom properties (variables) for easy theming:
- Primary colors are defined in `:root` in `styles.css`
- You can easily change the color scheme by updating these variables

### 5. Photo
Replace the placeholder in the About section:
- Add your photo to the project folder
- Update the image path in the HTML
- Or replace the placeholder div with an actual image

## Getting Started

1. **Open the website**: Simply open `index.html` in your web browser
2. **Customize**: Follow the customization guide above
3. **Deploy**: Upload to GitHub Pages, Netlify, or any web hosting service
